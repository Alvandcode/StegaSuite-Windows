## StegaSuite چیست؟

**StegaSuite** با تکنیک **Steganography** (نهان‌نگاری) هر فایلی را داخل یک فایل دیگر پنهان می‌کند. برخلاف رمزنگاری معمولی (مثل ZIP رمزدار) که تابلوست چیزی رمز شده، اینجا فایل خروجی **کاملاً عادی** به نظر می‌رسد — کسی که عکس/صدا را می‌بیند حتی نمی‌فهمد چیزی داخلش هست.

```
📷 فایل حامل + 📄 فایل مخفی + 🔑 رمز (اختیاری) → 🔒 فایل خروجی عادی
```

## راهنمای مخفی‌سازی و استخراج

**مخفی‌سازی (Hide):**

1. وارد تب مخفی‌سازی شوید و یک فایل حامل انتخاب کنید (PNG ،BMP ،WAV یا هر فایل).
2. فایل محرمانه را انتخاب کنید و در صورت نیاز رمز بگذارید.
3. روی دکمه مخفی‌سازی بزنید و فایل خروجی را ذخیره کنید.

**استخراج (Extract):**

1. وارد تب استخراج شوید و فایل حاوی داده را انتخاب کنید.
2. اگر موقع مخفی‌سازی رمز گذاشته‌اید، همان رمز را وارد کنید.
3. روی دکمه استخراج بزنید و فایل بازیابی‌شده را ذخیره کنید.

## گام صفر: ورود / ساخت حساب

برنامه بدون ورود باز نمی‌شود (صفحه لاگین تمام‌صفحه):

1. **ثبت‌نام:** نام کاربری + رمز + تکرار رمز → «ساخت حساب».
2. **کد بازیابی یک‌بارمصرف** را همان لحظه یادداشت کن! با آن + فایل بکاپ می‌توانی رمز فراموش‌شده را برگردانی.
3. **ورود:** نام کاربری + رمز → «ورود به برنامه». یا دکمه **Google** برای ورود با حساب گوگل (مرورگر سیستم باز می‌شود، PKCE + redirect روی loopback).
4. **فراموشی رمز:** از صفحه ورود → «فراموشی رمز» → فایل `*.stegabak` + کد بازیابی را بده → رمز جدید تعیین کن.
5. **بکاپ:** از ⚙️ تنظیمات → دریافت فایل بکاپ (`*.stegabak`، رمزنگاری‌شده با AES-256-GCM). زبان/تم هر کاربر جداگانه ذخیره می‌شود.

## آموزش مخفی‌سازی (قدم‌به‌قدم)

### گام ۱: انتخاب فایل حامل (Carrier)

فایلی که قرار است چیز داخلش قایم شود. بعد از عملیات ظاهرش عادی می‌ماند.

1. از سایدبار کپسولی سمت راست، تب **🏠 خانه** را بزن (حالت پیش‌فرض).
2. در کارت «فایل حامل» روی **انتخاب فایل...** کلیک کن — یا فایل را **بکش و داخل فیلد رها کن** (درگ‌دراپ).
3. اطلاعات نمایش داده می‌شود: نوع فرمت، نام، اندازه و **ظرفیت مخفی‌سازی**.
4. نقطه وضعیت بالای صفحه (سبز/قرمز) + باکس لاگ نتیجه را اعلام می‌کنند.

> ⚠️ **هشدار فرمت Lossy:** اگر حامل JPEG/WebP/MP3/MP4 باشد، کیفیت ممکن است دیتا را خراب کند. برای نتیجه مطمئن از **PNG یا BMP یا WAV** استفاده کن.

### گام ۲: انتخاب فایل مخفی‌شونده (Payload)

هر فایلی با هر پسوندی: متن، عکس، صدا، ویدیو، PDF، ZIP و...

1. در کارت دوم روی **انتخاب فایل...** کلیک کن (درگ‌دراپ هم کار می‌کند).
2. نام و اندازه فایل نمایش داده می‌شود.
3. اگر حجم payload از ظرفیت حامل بیشتر باشد، برنامه خطا می‌دهد — حامل بزرگ‌تر انتخاب کن یا فایل را ZIP کن.

### گام ۳: رمز عبور (اختیاری ولی پیشنهادی)

1. در فیلد «رمز عبور» یک رمز بگذار (دکمه 👁️ نمایش/پنهان).
2. با رمز → داده قبل از مخفی‌سازی با **AES-256-GCM** رمز می‌شود (Defense in Depth).
3. بدون رمز → فقط CRC32 ذخیره می‌شود (مخفی هست ولی رمزنگاری نشده).

> ⚠️ رمز را فراموش نکنی! بدون رمز هیچ راه برگشتی نیست.

### گام ۴: مخفی‌سازی و ذخیره

1. روی دکمه **«مخفی کن و ذخیره کن»** کلیک کن.
2. وضعیت «در حال پردازش...» می‌آید (معمولاً چند ثانیه).
3. دیالوگ Save ظاهر می‌شود — اسم پیشنهادی `(st)` دارد، مثلاً `photo(st).png`.
4. مسیر در لاگ + باکس وضعیت نمایش داده می‌شود و عملیات در **History** ثبت می‌شود.

## آموزش استخراج

1. از سایدبار تب **🔓 استخراج** را بزن.
2. فایل حاملِ حاوی دیتای مخفی را انتخاب کن (درگ‌دراپ هم می‌شود).
3. اگر موقع مخفی‌سازی رمز گذاشته بودی، همان رمز را وارد کن.
4. روی **«استخراج فایل مخفی»** کلیک کن.
5. فایل با **نام و پسوند اصلی** ذخیره می‌شود (نه `recovered_file` — مگر فایل مال نسخه خیلی قدیمی V1 باشد).

> 💡 تشخیص با Magic Bytes است نه پسوند؛ حتی اگر اسم/پسوند حامل را عوض کرده باشی، استخراج کار می‌کند.

## جزئیات رمزنگاری

### لایه اول: LSB

کم‌اهمیت‌ترین بیت هر پیکسل/نمونه/بایت عوض می‌شود — تغییر رنگ حداکثر ۱ از ۲۵۵، غیرقابل تشخیص.

### لایه دوم: AES-256-GCM (اگر رمز بگذاری)

| پارامتر | مقدار |
|---------|-------|
| الگوریتم | AES/GCM/NoPadding |
| کلید | ۲۵۶ بیت |
| استخراج کلید | PBKDF2WithHmacSHA256 |
| تکرار | ۶۰۰٬۰۰۰ |
| Salt | ۱۶ بایت (SecureRandom) |
| Nonce | ۱۲ بایت (SecureRandom) |
| تگ GCM | ۱۲۸ بیت |

### ساختار فایل خروجی

```
┌──────────────────────────────────────────────┐
│ Magic: SGP2 / SGF1 / SGA1      (4 bytes)     │
│ Payload Length                 (8 bytes)     │
│ ┌──────────────────────────────────────────┐ │
│ │ Encrypted/CRC'd Payload                  │ │
│ │  Filename Length (4 bytes)               │ │
│ │  Filename UTF-8 (≤1024 bytes)            │ │
│ │  File Content (N bytes)                  │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

## محاسبه ظرفیت

| نوع حامل | فرمول | مثال |
|----------|-------|------|
| PNG/BMP | `(عرض × ارتفاع × 3) ÷ 8` | تصویر ۱۹۲۰×۱۰۸۰ ≈ ۷۷۷ KB |
| WAV | `(نمونه‌ها × کانال‌ها) ÷ 8` | صدای ۱۰ ثانیه ۴۴.۱kHz ≈ ۲۵۹ KB |
| عمومی | `(اندازه فایل − بایت امن) ÷ 8` | فایل ۱ MB ≈ ۱۲۲ KB |

> ۵۰ بایت برای هدر + سربار رمزنگاری (Salt/Nonce/Tag) کم کن. برای راهنما: عکس ۱۲ مگاپیکسل ≈ ۴.۳ MB جا می‌دهد؛ صدای ۱ دقیقه WAV ≈ ۱.۵ MB.

## محدودیت‌ها و نکات امنیتی

| محدودیت | راه‌حل |
|---------|--------|
| فایل مخفی max ۵۰ MB | ZIP کن یا تکه‌تکه کن |
| نام فایل max ۱۰۲۴ بایت (≈۳۴۰ حرف فارسی) | اسم کوتاه‌تر |
| JPEG/WebP ممکن است خراب کنند | PNG/BMP/WAV |
| ویرایش حامل بعد از مخفی‌سازی (crop/resize/filter) دیتا را نابود می‌کند | فایل خروجی را دستکاری نکن |
| ارسال با تلگرام/ایمیل ممکن است فشرده‌سازی کند | فایل را ZIP کن بعد بفرست |

- رمز قوی (حروف+عدد+نماد) بگذار و جایی امن نگه دار.
- از خروجی + فایل بکاپ حساب، نسخه پشتیبان بگیر.
- فایل‌های V1 قدیمی (`SGP1`) بدون نام اصلی استخراج می‌شوند (`recovered_file`) — طبیعی است.

## سازگاری با نسخه اندروید

- مجیک‌بایت‌ها، چیدمان پکت، ترتیب بیت‌ها (MSB-first)، فرمول ظرفیت و پارامترهای رمز **عیناً یکسان** — رفت‌وبرگشت بین ویندوز و اندروید برای PNG/BMP/WAV سالم است.
- ⚠️ یک باگ مسیر فایل عمومی در اندروید هست (`hide` هر بیت را در LSB یک بایت می‌نویسد ولی `readBits` هر بایت را به ۸ بیت باز می‌کند) که در این پورت ویندوز **فیکس شده**. پس فایل‌های Generic ویندوز بین خودشان سالم‌اند ولی با اندروید فعلی روی همین دسته ناسازگارند؛ با همان اصلاح یک‌خطی در اندروید، سازگاری کامل می‌شود.

🤖 نسخه اندروید را از اینجا بگیر: [Releases اندروید](https://github.com/Alvandcode/StegaSuite/releases) — ریپو: [Alvandcode/StegaSuite](https://github.com/Alvandcode/StegaSuite)

## بیلد از سورس

```bat
cd StegaSuite-Windows
dotnet build StegaSuite.Wpf.csproj -c Release
dotnet publish StegaSuite.Wpf.csproj -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true -o publish
```

## تست‌ها

```bat
:: ۱۱ تست رفت‌وبرگشت موتور (رمزنگاری + PNG/BMP/WAV/Generic)
dotnet run --project Tests\Tests.csproj -c Release

:: سلف‌تست UI: سه سایز پنجره × ۵ زبان × ۹ تم × ۶ صفحه، بدون نمایش پنجره
dotnet run --project StegaSuite.Wpf.csproj -c Release -- --selftest
```

## فعال‌سازی ورود گوگل در بیلد شما

1. در Google Cloud Console یک OAuth Client از نوع **Desktop** بساز.
2. مقادیر را در `GoogleSecrets.cs` بگذار و rebuild کن.
3. ⚠️ هرگز مقادیر واقعی را در ریپوی عمومی کامیت نکن.

## ساختار

```
StegaSuite-Windows/
├── StegaSuite.Wpf.csproj   # اپ اصلی (net10.0-windows, WPF)
├── App.xaml(.cs)           # ورود + استایل دکمه‌ها (+ حالت --selftest)
├── MainWindow.xaml(.cs)    # هر ۶ صفحه + دیکشنری ۵زبانه
├── SelfTest.cs             # تست headless چیدمان
├── HistoryStore.cs / HistoryWindow.xaml(.cs)  # تاریخچه
├── AuthStore.cs / GoogleAuth.cs / GoogleSecrets.cs  # حساب + گوگل
├── Themes/                 # ۹ تم XAML (DynamicResource)
├── Core/                   # موتور سازگار با اندروید
│   ├── StegaCrypto.cs          # AES-256-GCM + PBKDF2 (600K)
│   ├── PngSteganography.cs     # موتور تصویر SGP2 (خواندن SGP1 هم دارد)
│   ├── FileSteganography.cs    # موتور فایل عمومی SGF1
│   ├── AudioSteganography.cs   # موتور صوت WAV با SGA1
│   └── Common.cs               # CarrierType + ExtractResult + CRC32
├── Tests/                  # تست‌های موتور
├── Installer/              # نصب بدون وابستگی (Install.bat/Install.ps1)
└── Assets/                 # آیکون و آرت‌ورک
```
