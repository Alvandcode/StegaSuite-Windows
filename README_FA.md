# StegaSuite — نسخه ویندوز (Windows Edition, v2 WPF)

**زبان:** **فارسی** | [English](README.md)

پورت کامل و سازگارِ اپ اندرویدی [StegaSuite](https://github.com/Alvandcode/StegaSuite) برای ویندوز ۱۰/۱۱.
تکنولوژی: **C# + WPF + .NET 10** — تک‌فایل اجرایی، کاملاً آفلاین، ریسپانسیو و مستقل از DPI.

## اجرا (سریع، پرتابل)

```bat
StegaSuite-Windows\publish\StegaSuite.exe
```

> نیاز به [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download) دارد.

## نصب (نسخه نصبی)

فایل `Installer\StegaSuite-Setup-2.0.0.zip` را باز کنید و روی `Install.bat` دابل‌کلیک
کنید (دسترسی ادمین می‌خواهد؛ بدون ادمین، نصب کاربر-محور انجام می‌شود).
نصب‌کننده نسخه خودکفا (بدون نیاز به دانلود .NET) را در Program Files می‌گذارد،
میانبر استارت‌منو/دسکتاپ می‌سازد و در Add/Remove Programs ثبت می‌کند.
حذف از همان‌جاست. دیتای کاربر (`%AppData%\StegaSuite`) با حذف برنامه پاک نمی‌شود.

> ریلیزها با GitHub Actions روی هر تگ نسخه خودکار ساخته می‌شوند
> (`git tag vX.Y.Z && git push origin vX.Y.Z`).

## سیستم‌عامل‌های پشتیبانی‌شده

ویندوز ۱۰ (نسخه 1809 به بعد) و ویندوز ۱۱ — نسخه ۶۴بیتی.
پشتیبانی از XP/Vista/7/8 با این تکنولوژی ممکن نیست: موتور AES-256-GCM و
TLS لازم برای ورود گوگل روی آن‌ها وجود ندارد و خود مایکروسافت هم سال‌هاست
پشتیبانی‌شان را تمام کرده (XP از ۲۰۱۴). روی ویندوز ۱۰/۱۱ همه‌چیز آفلاین
کار می‌کند و فقط ورود گوگل اینترنت می‌خواهد.

## بیلد از سورس

```bat
cd StegaSuite-Windows
dotnet build StegaSuite.Wpf.csproj -c Release
dotnet publish StegaSuite.Wpf.csproj -c Release -r win-x64 --self-contained false /p:PublishSingleFile=true -o publish
```

## فعال‌سازی ورود گوگل در بیلد شما

دکمه Google برای کار کردن به اعتبار OAuth نوع Desktop نیاز دارد:
1. در Google Cloud Console یک OAuth Client از نوع **Desktop** بسازید.
2. مقادیر واقعی را در فایل `GoogleSecrets.cs` بگذارید و rebuild کنید.
3. ⚠️ هرگز مقادیر واقعی را در ریپوی عمومی کامیت نکنید.

## تست‌ها

```bat
:: ۱۱ تست رفت‌وبرگشت موتور (رمزنگاری + PNG/BMP/WAV/Generic)
dotnet run --project Tests\Tests.csproj -c Release

:: سلف‌تست UI: سه سایز پنجره × ۵ زبان × ۶ تم × ۶ صفحه (۵۴۰ ترکیب)، بدون نمایش پنجره
dotnet run --project StegaSuite.Wpf.csproj -c Release -- --selftest
```

## رابط کاربری (WPF)

سبک **bento کپسولی**: کارت بیرونی گرد، سایدبار کپسولی با تب‌ها، کارت قهرمان،
فیلدهای گرد با درگ‌دراپ، کنسول لاگ. چیدمان Grid/XAML کاملاً ریسپانسیو است
(اسکرول در پنجره کوچک، کش‌آمدن در پنجره بزرگ) و گوشه‌های گرد بدون هیچ Region
دست‌سازی رسم می‌شوند، پس زیر اسکیل ۱۲۵٪/۱۵۰٪ ویندوز هم سالم می‌ماند.

**تب‌های سایدبار:** 🏠 خانه (مخفی‌سازی) • 🔓 استخراج • ℹ️ درباره برنامه •
✉️ تماس با ما • ❤️ حمایت • ⚙️ تنظیمات

**حساب کاربری (آفلاین):** در اولین اجرا یک حساب محلی می‌سازید (نام کاربری + رمز).
رمزها فقط به‌صورت PBKDF2-HMAC-SHA256 هش‌شده نگه‌داری می‌شوند و برنامه بدون ورود
باز نمی‌شود. بعد از ثبت‌نام یک **کد بازیابی یک‌بارمصرف** می‌گیرید؛ با آن از
بخش تنظیمات **فایل بکاپ** (`*.stegabak`, رمزنگاری‌شده با AES-256-GCM) دریافت کنید.
اگر رمز را فراموش کردید، از صفحه ورود با «فراموشی رمز» و همان فایل + کد، حساب را
بازیابی و رمز جدید تعیین می‌کنید. تنظیمات زبان/تم هر کاربر جداگانه ذخیره می‌شود.

**ورود واقعی با گوگل (OAuth2):** دکمه Google در صفحه ورود، فلوی استاندارد گوگل
برای اپ‌های دسکتاپ را اجرا می‌کند (مرورگر سیستم + PKCE + redirect روی loopback؛
بدون هیچ کتابخانه اضافه). اعتبار گوگل (Client ID و Secret از نوع Desktop) داخل
فایل `GoogleSecrets.cs` در سورس دفن شده و کاربر نهایی هیچ‌وقت آن‌ها را نمی‌بیند؛
برای همین ورود با گوگل برای همه out-of-the-box کار می‌کند.
⚠️ همین یک نکته امنیتی: این فایل را خصوصی نگه دارید؛ اگر روزی سورس را جایی
منتشر کردید، اول مقادیرش را پاک (و در کنسول گوگل rotate) کنید.

**تنظیمات:** ۵ زبان (فارسی، العربية، English، Русский، 中文 — فارسی/عربی راست‌چین
با FlowDirection واقعی) و ۹ تم — ۴ تیره (بنفش، آبی سایبری، زرشکی، خاکستری تیره)
و ۵ روشن (صورتی، نعنایی، یاسی، سفید زغال‌سنگی، کرمی روشن).
قانون کنتراست سراسری: متن همیشه برعکس سطح است (روشن روی تیره، تیره روی روشن).
تم‌ها فایل‌های XAML مستقل در `Themes/` هستند و با DynamicResource زنده عوض می‌شوند.

## ساختار

```
StegaSuite-Windows/
├── StegaSuite.Wpf.csproj   # اپ اصلی (net10.0-windows, WPF)
├── App.xaml(.cs)           # نقطه ورود + استایل دکمه‌ها (+ حالت --selftest)
├── MainWindow.xaml(.cs)    # هر ۶ صفحه + دیکشنری ۵زبانه
├── SelfTest.cs             # تست headless چیدمان
├── Themes/                 # ۶ تم (Purple, CyberBlue, Crimson, Rose, Mint, Lavender)
├── Core/                   # موتور سازگار با اندروید (بدون تغییر)
│   ├── StegaCrypto.cs          # AES-256-GCM + PBKDF2-HMAC-SHA256 (600K)
│   ├── PngSteganography.cs     # موتور تصویر SGP2 (خواندن SGP1 قدیمی هم دارد)
│   ├── FileSteganography.cs    # موتور فایل عمومی SGF1
│   ├── AudioSteganography.cs   # موتور صوت WAV با SGA1
│   └── Common.cs               # CarrierType + ExtractResult + CRC32
├── Tests/                  # ۱۱ تست موتور
└── publish/                # خروجی آماده اجرا (StegaSuite.exe)
```

## سازگاری با نسخه اندروید

- مجیک‌بایت‌ها (`SGP2/SGP1/SGF1/SGA1/STGS`)، چیدمان پکت، ترتیب بیت‌ها (MSB-first)،
  فرمول ظرفیت و پارامترهای رمزنگاری **موشکافانه یکسان** پیاده شده‌اند؛
  فایل ساخته‌شده در ویندوز در اندروید باز می‌شود و برعکس (برای PNG/BMP/WAV).
- ⚠️ **یک باگ نسخه اندروید در پورت ویندوز فیکس شده:** در `FileSteganography.kt`
  تابع `hide` هر بیت را در LSB یک بایت حامل می‌نویسد ولی `readBits` هر بایت را
  به ۸ بیت باز می‌کند؛ یعنی مسیر فایل عمومی (non-PNG/BMP/WAV) در اندروید
  Hide و Extract متقارن نیست و عملاً خراب است. نسخه ویندوز هر دو سمت را
  درست (۱ بیت در هر بایت) پیاده کرده، پس فایل‌های عمومیِ ویندوز بین خودشان
  سالم رفت‌وبرگشت می‌شوند ولی با اندرویدِ فعلی روی این دسته سازگار نیستند.
   اگر در اندروید هم همین اصلاح اعمال شود، سازگاری کامل می‌شود.
